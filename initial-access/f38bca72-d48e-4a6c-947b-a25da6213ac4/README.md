# Default Account Remote Logon (AN1283)

## Metadata
- **Rule ID**: f38bca72-d48e-4a6c-947b-a25da6213ac4
- **Technique**: T1078.001

## Details
Detects remote or network logons (Logon Type 3 or 10) utilizing built-in default accounts like Administrator or Guest. These accounts are often targeted for lateral movement or initial access if exposed.

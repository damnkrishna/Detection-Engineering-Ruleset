# Content Injection - Execution of Web Server Configuration Tool (AN0992-B)

## Metadata
- **Rule ID**: fb332700-9bbf-42ae-a756-06878e3a9511
- **Technique**: T1659

## Details
Detects command-line executions modifying web server configuration files (like web.config, httpd.conf, nginx.conf) or utilizing IIS configuration tools (appcmd.exe).

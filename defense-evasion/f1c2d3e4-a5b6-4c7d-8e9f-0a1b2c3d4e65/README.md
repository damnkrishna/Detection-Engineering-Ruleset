# Steganography or Data Obfuscation Utility Execution (AN2108)

## Metadata
- **Rule ID**: f1c2d3e4-a5b6-4c7d-8e9f-0a1b2c3d4e65
- **Technique**: T1001

## Details
Detects the execution of steganography tools (like steghide) used to hide or extract data within seemingly benign files, a technique for data exfiltration or hiding C2 communications.

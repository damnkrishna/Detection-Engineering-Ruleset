# Artificial Execution Delay or Anti-Sandbox Sleep (AN2126)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c87
- **Technique**: T1678

## Details
Detects command-line parameters indicative of artificial execution delays, such as extended ping counts to localhost or long Start-Sleep commands, often used to bypass sandbox timeouts.

# Clear Windows Event Logs - CLI Utilities (AN1472)

## Metadata
- **Rule ID**: f30ea238-1a5c-411a-ab57-36eeb5452f36
- **Technique**: T1685.005

## Details
Detects the use of command-line utilities (like wevtutil or PowerShell cmdlets) to clear Windows event logs, a common technique used by adversaries to hide their activity and impair defenses.

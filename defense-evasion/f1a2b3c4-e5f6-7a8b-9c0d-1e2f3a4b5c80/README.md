# Microsoft Office Application Spawning Script Interpreter (AN2119)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c80
- **Technique**: T1221

## Details
Detects command-line script interpreters or shell utilities running as child processes of Microsoft Office applications, which is a common indicator of remote template injection or macro-based execution.

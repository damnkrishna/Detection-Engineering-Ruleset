# Input Keystroke Automation or Injection Tool Execution (AN2125)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c86
- **Technique**: T1674

## Details
Detects the execution of macro or scripting engines (like AutoIt or AutoHotkey) or PowerShell commands invoking SendKeys, often used for automated keystroke injection.

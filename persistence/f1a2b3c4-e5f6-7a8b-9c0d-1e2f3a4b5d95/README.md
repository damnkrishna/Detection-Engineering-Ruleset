# Privileged Account or Group Membership Manipulation (AN2114)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5d95
- **Technique**: T1098

## Details
Detects the addition of accounts to highly privileged groups (e.g., Domain Admins) or suspicious modifications to user account control flags (like disabling pre-authentication), often used by adversaries to establish persistence or escalate privileges.

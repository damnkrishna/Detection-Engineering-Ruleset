# Malicious Office Add-in Drop for Persistence (AN0137-B)

## Metadata
- **Rule ID**: f491ca8d-71b3-4f9c-be82-f5da771bc39a
- **Technique**: T1137.006

## Details
Detects the writing of malicious Office add-in files (.wll, .xll, .xlam, etc.) to specific startup or add-in directories, often used by adversaries to establish persistence across reboots.

# System Firmware or BIOS Flash Utility Execution (AN2121)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c82
- **Technique**: T1542

## Details
Detects the execution of known bios flash utilities, motherboard firmware tools, or command lines modifying UEFI settings, indicating potential pre-OS boot persistent modification.

# Collection - Clipboard Data Retrieval Command (AN0965)

## Metadata
- **Rule ID**: 07461075-1fb8-449a-8fea-78b6b9667d5b
- **Technique**: T1115

## Details
Detects command-line parameters or PowerShell scripting commands executing clipboard-reading commands (such as Get-Clipboard or clipboard APIs), suggesting unauthorized credential or data harvesting.

# Collection - Screen Capture Utility Execution (AN0980)

## Metadata
- **Rule ID**: 19277629-f4d9-48f1-b0f3-345326e2f695
- **Technique**: T1113

## Details
Detects command-line utilities (psr.exe, nircmd.exe) or PowerShell scripting commands executing screen capture API calls, suggesting unauthorized information gathering.

# Collection - Archiving or Encryption via Custom Method (AN1213)

## Metadata
- **Rule ID**: 159ffe92-2ec0-4e1d-86b4-a3714066b35b
- **Technique**: T1560.003

## Details
Detects PowerShell or scripting engines executing low-level cryptographic or compression APIs to perform custom file archiving/encryption, bypassing standard archiving controls.

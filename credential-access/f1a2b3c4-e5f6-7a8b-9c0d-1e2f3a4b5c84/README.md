# Authentication Certificate or Private Key Export Tool Execution (AN2123)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c84
- **Technique**: T1649

## Details
Detects the execution of tools designed for exporting authentication certificates or private keys, potentially for unauthorized access or persistent access.

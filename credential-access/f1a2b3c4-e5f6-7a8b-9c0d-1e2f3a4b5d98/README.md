# Custom Security Support Provider or LSA Package Registration (AN2115)

## Metadata
- **Rule ID**: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5d98
- **Technique**: T1111

## Details
Detects modifications to Local Security Authority (LSA) configuration registry keys to register new Security Support Providers (SSPs) or Authentication Packages, which can allow adversaries to harvest plaintext credentials.

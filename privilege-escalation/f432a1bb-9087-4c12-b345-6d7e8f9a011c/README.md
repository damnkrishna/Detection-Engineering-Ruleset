# Suspicious Process Access indicating EWM Injection (AN0608)

## Metadata
- **Rule ID**: f432a1bb-9087-4c12-b345-6d7e8f9a011c
- **Technique**: T1055.011

## Details
Detects adversary manipulation of Extra Window Memory (EWM) by monitoring for suspicious ProcessAccess requests targeting GUI processes like explorer.exe.
